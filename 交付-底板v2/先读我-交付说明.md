## 已落实的电路修改

| 原问题 | v2 的处理 |
|---|---|
| D1 单向 TVS 方向错误、反接回路不清楚 | 改双向 SMBJ30CA / C83847，接保险后 VIN_F 对 GND；反接由串联 SS310 / C15874 阻断 |
| C1 在防反接前、原物料仅 35 V | 改在 VBAT 后，用 Panasonic EEUFR1J101 / C407952，100 µF / 63 V；C2、C4、C23 也在保护后 |
| 30 V MOS、40 V 降压与约 48.4 V TVS 不配合 | 取消输入 P-MOS、旧 TPS5430 和续流 D2；使用 100 V 串联二极管、65 V LMR36520、100 V 输入陶瓷及 63 V 电解 |
| C5/补偿网络依据不足 | 换成 LMR36520 的 5 V 参考网络：10 µH、2×22 µF/25 V、100 kΩ/24.9 kΩ反馈 |
| 电池有 2S/6S/7S 三种写法 | 本版统一 7S/29.4 V；软件分压改 19 倍，欠压门限 22.4 V（受保护 VBAT 测量值），需要实物校准 |
| MOTOR_EN 没接执行器 | 接入硬件与门、手动锁存、PWM 门控和外部动力继电器驱动 |
| 急停只有软件、断线不能检出 | J4 改常闭辅助触点，开路/断线为低；急停第二组常闭触点直接切断外部 5 V 动力继电器线圈 |
| MCU 卡死不能靠下拉检出 | 新增 TPS3820-33 外部看门狗，200 ms 典型超时清除手动使能；WDI 用厂家建议的 1 kΩ下拉，防悬空自动禁狗 |
| 解除急停/复位可能自行恢复 | 硬件锁存故障时清除，必须释放再按 ARM；PC13 读取 ARM 状态；软件要求使能后先松踏板再踩 |
| 核心板 Micro-USB 5 V 回灌 | JP1 可切断底板到核心板的 5 V；**插核心板 Micro-USB 前必须先断电、拔掉 JP1 短路帽**。现有核心板不改，不能支持任意双电源插法 |
| 底板 USB 与降压供电互相回灌 | LM66200 双理想二极管；CH340 只由 USB VBUS 供电；UART 两方向加 Ioff 缓冲 |
| 核心板 3.3 V 带外设负载不明确 | 独立 AP2112M-3.3，外设总预算 200 mA，与 CORE_3V3 分网；由核心电源使能 |
| 核心断电时踏板/ACS712 回灌 | +5V_SENS 加受 CORE_3V3 控制的高边开关；核心 3V3 加 1 kΩ泄放。电池采样仍有限流钳位，禁止带电拔核心板 |
| 霍尔踏板 5 V 输出不能直接进 ADC | 10 kΩ/15 kΩ分压，1 kΩ串阻、100 nF滤波和 BAT54S 钳位到 CORE_3V3；软件按 0.8–4.2 V 映射并检测异常范围 |
| 方案需要两只 FSR，仅有一路 | J7/PB0 左、J20/PB1 右，两路独立采集；默认任一有压力即判有人，门限待称重标定 |
| J3 中脚接地可能短路电调 BEC | 改 1=信号、2=NC、3=GND，BEC 线绝缘悬空；仍要核实实物插头方向 |
| 蜂鸣器 Q2 集电极断网 | 明确接入 BUZZ_COL，补 BE 下拉和续流；GPIO 改 PA15 |
| USB/晶振与 GPIO 冲突 | PA11/PA12留给核心 USB，PC14/PC15留给 32.768 kHz晶振；ToF XSHUT 改 PB3/PB9、NFC_RST 改 PB8；固件释放 JTAG、保留 SWD |
| ToF/NFC 需额外分线 | 左右 ToF 各 6 针接口；NFC独立 8 针，含复位；与 IMU 共用 SPI 的片选均有上拉 |
| 原 PCB 与原理图不同步 | 重新生成所有元件、库引用及焊盘网络；旧元件、旧网络和旧板框不沿用；等待正式布局布线 |

**关于 C2：普通无极性 MLCC 的额定电压按两端电压绝对值判断，不能笼统地说电池反接就会因“反向电压”击穿。** 本版把 C2 放在保护后的 VBAT 是统一滤波位置和故障边界的选择；它仍需满足实际浪涌耐压。

## 参数与实施边界

- 5 V 名义输出：1.0×(1+100/24.9)=5.016 V；U1 额定 2 A，但底板设计负载限制为 **1.2 A 连续、峰值不超过 1.8 A**，实际受 PCB 散热和 USB 电源能力限制。
- 建议连续预算：核心 100 mA、ESP32开发板 300 mA、3V3外设经LDO 200 mA、继电器线圈 200 mA、其他传感器/蜂鸣/逻辑 150 mA，合计约 950 mA，留约 250 mA余量。峰值另测。4G、灯环、大音量功放不能占用这一路。
- AP2112M 最坏按 200 mA、5.25 V 输入约 0.39 W，手册 SO8 θJA 114 °C/W 估算温升约 44 °C；必须留铜并测温。200 mA 是所有 3V3 外设合计，不是每个接口各 200 mA。
- U1 EN 分压 180 kΩ/10 kΩ：按典型 1.231 V阈值约 VBAT 23.39 V启动、约 21.30 V下降关闭；**不是精密 BMS 门限**，有参考误差/电阻误差/二极管压降，最终以限流电源扫压实测为准。7S电池仍必须自带BMS。
- 电池分压 180 kΩ/10 kΩ，29.4 V→1.547 V，48.4 V→2.547 V。软件测的是 D11 后的VBAT，电池端电压高出二极管压降；不要直接拿它当精确单体电压。
- TVS 的 48.4 V 是规定脉冲条件下的最大钳位参数，不是任意浪涌的硬上限。TVS和板上保险的脉冲能量/I²t尚未配合实测；电池正极附近需另装足够直流分断能力的支路保险，不能只靠板上1A贴片保险承受电池短路。
- D11 有压降、发热和热插拔浪涌；输入电解改 100 µF 是配合厂家推荐的20–100 µF输入阻尼，并减少插拔涌流，**不是把旧470 µF只换耐压**。
- 5V继电器线圈最大200 mA，Q3 为 AO3400A，**J18完全没有电池高压**；继电器主触点及电机主电流走车身线束，不能经过底板。
- 普通续流二极管会延长继电器释放时间；必须测断动力延迟、接点焊死风险和断开时母线尖峰。切断动力后车辆可能滑行，**本电路没有机械制动执行器**，不能把“撤销动力”称为已经完成制动/防撞安全认证。
- 外接电机/电调、动力继电器具体商品仍待采购：本版给出明确电气采购条件；标“24V”的商品不能自动视为兼容7S。没有拿到实物手册前不填造型号，也不能承诺继电器可安全分断堵转电流。

## 软件完成范围

已同步PA15蜂鸣、PB3/PB9 XSHUT、PB8 NFC复位、PB1右FSR、PC13手动使能反馈；PC13从上电初始化起始终为输入，HMI不再驱动核心板LED。同步7S电压换算、踏板有效窗口、双坐垫、双向过流幅值、欠压锁存；撤销使能时同时关闭PWM主输出，防止控制任务再写入旧油门；心跳与喂狗增加采集/控制任务进度检查；关闭串口调试覆盖和故障注入默认入口。

网关与小程序同步 29.4 V 的遥测：第6字节保留旧0.1V格式并在25.5V饱和；第12–13字节扩展为小端毫伏值；第11字节补故障高字节。小程序向后兼容旧帧，旧端若不更新仍只能显示最多25.5V。构建记录为STM32固件，网关已运行主机侧回归，未做完整ESP32板级构建与蓝牙/云端实测。

**没有把原有空驱动伪装成实现完成。IMU、双ToF、NFC白名单、真实轮速仍需实现和实物联调。** 当前固件遇到缺失或过期采样会禁止驱动，`APP_DRIVE_COMMISSIONED=0`保持关闭，所以不是烧录后就能载人运行的版本。倾覆判据只修正原来7000mg量级错误，采用安装轴+Z向上的45°几何判据，尚无姿态融合/动态过滤的实车验证。座椅、踏板、电流需标定；防撞距离、无信号停车行为、继电器断开工况均待验证。

OLED可共享I2C；WS2812灯环、语音功放、4G独立供电和制动执行机构仍属于外部扩展/后续设计，不在这个底板版本里。接口具备不等于这些功能已实现。

## 导入后到投板前必须完成

1. 在专业版导入新工程，核对6页及BOM；对所有本地库逐一核引脚类型、真实型号、极性和封装。当前引脚设为无源以保留明确连接关系，**官方ERC不能代替人工检查电源/输入/输出类型**。
2. 重新运行ERC，核对网络高亮；尤其J2A/J2B的实际朝向、两排15.24 mm间距、20针顺序、核心板USB及晶振占用。核对核心PC13板载LED负载与ARM高低电平。
3. 做PCB板框、元件布局、丝印、布线、铺铜、过孔与散热；U1热焊盘接地并做热过孔，输入高频环路/BOOT最短，SW远离反馈和ADC；传感器回流避开动力电流；所有接插件标引脚1、方向、电压。
4. 运行DRC及制造检查，核对所有新封装焊盘尺寸和引脚1标记；用核心板实物或1:1打印检验机械适配。只有这些通过才生成生产文件。
5. 首次上电用限流电源，先不插核心与外设。按下表逐项验证，再实现驱动和软件测试；测试阶段车轮悬空、无人员乘坐。

| 必测工况 | 通过条件 |
|---|---|
| 输入0→29.4V、欠压扫压、热插拔 | 5V/3V3正常，无超额尖峰；阈值和启动迟滞记录在案 |
| 限流条件下反接及带电容快速改极性 | VBAT不反向；二极管/TVS/保险无损坏，不能用裸电池直接试错 |
| 底板Type-C/电池单独与同时供电 | 不向USB回灌，功率预算满足；USB电脑口不承担动力 |
| 核心Micro-USB调试 | 先断电、移除JP1，再接核心USB；不得带短路帽双供电 |
| 按急停、拔急停线、停心跳、复位 | PWM被关断、线圈释放；恢复后不自动重启；记录实际最坏停止延迟 |
| ARM一直按住、踩踏板再ARM | 故障恢复不能自动重上膛；必须松开再按按钮，并先松踏板才允许运行 |
| 传感器拔掉/采样停止/任务挂起 | 进入禁止驱动，不能用4000mm假距离和0假车速继续行驶 |
| 踏板断线、对地/对5V故障 | 被识别为异常而非合法油门；单路霍尔不能覆盖卡在合法电压的所有故障 |
| 连续负载及无线发射峰值 | U1/L1/D11/U3/U4温升、纹波、压降合格，无复位或继电器抖动 |
