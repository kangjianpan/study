# 外部接口与采购要求

本表与v2工程对应，旧v1接线表不适用于v2。所有编号按底板引脚号，不按线色或图形上下位置猜。先核模块自身引脚，再做对应线束。

## 尚未采购的器材

| 项目 | 统一要求 |
|---|---|
| 电池 | 7S普通锂离子，25.9V标称/29.4V满充，约10Ah，自带适配电机启动电流的BMS；匹配7S/29.4V充电器。不是7S磷酸铁锂，也不是2S/6S |
| 电机 | 24V级250W左右有刷直流，厂家允许7S满电29.4V供电/相应占空比；主回路不过底板 |
| 电调 | 有刷、明确兼容7S锂电；50Hz舵机PWM，1500µs中立/零扭矩，1000–2000µs范围；3.3/5V信号兼容；上电先中立才上膛；信号恒低/丢失时停止且不能保持旧油门；电流能力覆盖电机堵转/启动，并可限制电流。禁止买只收0.8–4.2V模拟油门或仅6S的电调 |
| 踏板 | 5V霍尔三线，输出正常约0.8–4.2V，带回位弹簧；本版按10k/15k分压后读取。输出范围不同须重新计算、标定 |
| 动力继电器 | **5V直流线圈，线圈在5.25V时电流≤200mA，无内置与D12冲突的抑制器**；常开主触点，至少30VDC且电流按实际负载/堵转分断选择，目标持续≥20A，必须有明确直流电机/感性负载分断依据。不要按250VAC额定电流替代直流额定。外置安装；若买不到满足这些条件的，不得用24V线圈替代接J18，需重新设计线圈供电/驱动 |
| 急停 | 蘑菇头自锁、至少两组NC；一组切5V继电器线圈电流（≥200mA DC），另一组作J4辅助检测；复位不产生自动启动 |
| ARM按钮 | 独立常开瞬时按钮，接J17；不是保持式开关 |
| 电池保险 | 电池正极附近，直流额定≥32V，具有能覆盖实际电池短路电流的分断能力；主回路与底板分支分别保护；安培数按电机、电调及线径确定，板上F1不能替代 |
| ToF×2 | VL53L1X模块，3.3V供电/逻辑，具有独立XSHUT，地址重配置后共用I2C；不要把仅支持VIN=5V或带5V上拉的模块直接套入 |
| IMU | ICM-42688-P的3.3V SPI模块，核对自身稳压/电平，不能直接接未经处理的裸芯片到线束 |
| NFC | MFRC522 3.3V SPI模块+指定头盔NTAG213标签；线束按信号名适配，不按本底板排针顺序直插常见RC522板 |
| FSR×2 | 左右各一片，两端元件接该接口电源与RAW；默认10k下拉，量程与有人门限需加载标定 |
| 安全带/轮速 | 5V供电开集电极霍尔输出，底板上拉到3.3V；不要接5V推挽输出。轮速必须测每转脉冲数和有效轮径 |
| 电流采样 | ACS712-30A类5V模拟模块，66mV/A、零点2.5V；电机电流经过模块大电流端子，J16只接供电与模拟信号。模块路径的安全电流与隔离距离另核 |
| ESP32 | 带自身3.3V稳压的5V开发板，串口3.3V；J10由+5V_SENS供电，不另并USB供电，不把5V接裸模组3V3脚 |
| 4G/灯环/功放 | 独立外部电源与相应接口/电平适配，本版没有完整电路；不能挂在底板预算之外继续加负载 |

## 核心板引脚注意

J2A/J2B原两排20针排母沿用实物脚序，两排中心距15.24mm，必须按TLS尺寸图及实物方向布局。J2A-20为核心后备VBAT脚，保持NC，绝对不能接底板高压VBAT。

PC13（J2A-17）本版是ARM反馈输入，板载LED不能再由固件控制；PA15蜂鸣、PB3左XSHUT需关闭JTAG但保留SWD。PA11/PA12与PC14/PC15保持底板不连接，分别留给USB和低速晶振。

## 动力回路

```text
电池正极 ─ 主保险 ─ 继电器主常开触点 ─ 有刷电调电源+ ─ 电机
电池负极 ────────────────────── 电调电源-
电池正极 ─ 底板分支保险 ─ J1正极
电池负极 ───────────── J1负极/GND

J18-1 (+5V) ─ 急停NC动力触点 ─ J18-2 (COIL_PLUS) ─ 5V线圈+
J18-3 (COIL_LOW) ────────────────────────────── 5V线圈-
J4-1 (ESTOP_FEED) ─ 急停另一组NC辅助触点 ─ J4-2 (ESTOP_RETURN)
J17-1 (ARM_BTN) ─ 常开瞬时ARM按钮 ─ J17-2 (GND)
J3-1 (ESC_PWM) ─ 电调信号；J3-2悬空；J3-3 ─ 电调信号地
```

D12跨接COIL_PLUS/COIL_LOW，在常闭开关下游吸收线圈反压。不要把续流管跨到急停开关上。电调BEC正电源那根线剪断处应绝缘或从插壳退针，不能接J3-2，也不能与底板5V并联。主动力不经过J18、板上F1或底板铜线。

**必接项：J18-1 → 外部急停NC动力触点 → J18-2 的回路不能遗漏，也不允许用板上短接替代。** 断电后用通断档检查该急停线束：按钮释放时导通、按下时断开。COIL_PLUS 在板上不直接连 +5V 是设计要求。

安全带/轮速必须采用开集电极输出；若模块自带信号上拉到5V，需先处理上拉/电平后再接入。Q4/Q5 由 CORE_3V3 自动控制供电，防止核心板断电回灌，不能删除后直连 +5V。最新固件实现及实物待验收项见 `../童骑卫-FW/联调与验收.md`。

电调上电与接触器闭合后可能需要持续中立若干秒才能上膛，此时间必须按购买型号实测；本版源码未实现真实车速和全套驱动，不可用“未转动”作为已验证安全的依据。
