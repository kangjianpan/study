# 5块底板采购与代焊

本次按5块底板装配准备，保留当前设计的全部139个位号、52种物料。每块116个贴片件、23个插件，整批分别为580个和115个，总计695个元件。现有核心板不在底板BOM内，只有两排插座在BOM内。

## 文件怎么用

- `5块底板采购清单.xlsx`：合并型号后的用量、LCSC查询库存、商品页、缺货备选和辅料。人民币报价单价留空，填写嘉立创实际报价后计算5块的元件料费；不含PCB、工艺、装配、运费及额外损耗。
- `贴片BOM-每块用量.csv`：用于贴片询价和选料。字段包含型号、位号、封装、立创编号、每块数量。下单界面选装配5块，文件内的Quantity仍是每块数量，不要再乘5。
- `插件BOM-每块用量.csv`：插件用料，先确认嘉立创本次订单能否代焊；未包含在代焊范围的再自行购买，避免重复采购。
- `缺货备选.csv`：单独列出备选，不会自动修改原理图、PCB或上述原号BOM。

2026-11-17逐项查询了LCSC公开商品目录，52个原编号均对应现有BOM型号。库存为该次目录返回值，**不代表嘉立创贴片料库已锁料，也不等于国内商城库存或人民币报价**。资料来源与工程哈希保存在 `../检查记录/采购目录核对.json`。LCSC返回的美元价格未当作国内报价使用。

## 选料处理

原型号优先。公开目录中以下5种返回库存0，涉及42个元件/块；国内下单时如果原号可用，就继续用原号。若缺货，可依备选表选料：

| 原编号 | 备选编号及型号 | 处理 |
|---|---|---|
| C14663 | C314282 / 0603B104K500CT | 100nF、50V、X7R、±10%、0603，报价备选 |
| C17266784 | C1870804 / 12101C475K4Z2A | C4/C23：4.7uF、100V、X7R、1210；目录参数一致，尚缺精确型号的DC偏压及厚度核对，暂不直接替换生产 |
| C25819 | C965160 / NQ03WAF4702T5E | 47kΩ、1%、100mW、75V、0603，报价备选 |
| C21190 | C2758735 / NQ03WAF1001T5E | 1kΩ、1%、100mW、75V、0603，报价备选 |
| C97890 | C106248 / CC0603KRX7R7BB105 | 1uF、16V、X7R、±10%、0603，报价备选 |

`C25804`（10kΩ）目录库存仅100个，5块安装需80个，余量较小；`C70285`（U8）目录库存65个，安装需5个。实际选料还需计入工厂送料损耗。

不能只按“看起来一样”替换逻辑芯片、稳压器或三极管，尤其要保留U10的AHCT逻辑系列、U5的看门狗型号，以及U3/U1的准确封装和引脚。

## 代焊提交

1. 在嘉立创EDA里打开最终保存、用户已确认DRC为0的工程，从该版本导出生产Gerber、BOM和坐标文件。该采购包不包含Gerber和坐标文件，不能单独作为完整生产资料。
2. PCB数量和装配数量均选5块。先上传贴片BOM，在选料页面逐行确认编号、型号、封装、供货和价格。若页面要求其他模板，映射对应字段，不要自动猜列。
3. 当前工程139个元件的放置层均为顶层；插件通常另核代焊范围。J15 USB-C属于贴片BOM，虽有定位孔仍应让工厂确认支持工艺。
4. 核对贴片预览的方向、Pin1和极性，重点是U1/U3散热及细间距封装、U8、二极管、LED、USB-C。坐标应使用EDA正式导出结果，不拿预览图推算。
5. 保留C1电解、排针/排母、端子和SW1的插件清单。若工厂能代焊则加入对应工序，否则按整批用量另购。自行采购还要按商城起订量取整，并增加适量备用件；工厂配料的贴片件不必再买一份。
