2026-11-17 根据在线编辑器的 11 项“挖槽区域到导线”报错，修复 USB-C（J15）的两个 0.6 mm 定位孔附近走线。e50、e51 到最近走线的距离分别为 **0.331 mm、0.435 mm**，均满足 0.3 mm 要求。保留定位孔，并调整 USB 电源、地线和底层传感器 5 V 电源走线；顶、底层 GND 铺铜已重建，避让定位孔 0.35 mm，并合并了重叠的底层铺铜定义。

本次基于用户执行“导入更新”后的工程，保留已同步的元件、封装及焊盘网络，也同步了逐脚网表中四条自动命名网络的大小写。修复前的用户工程保存在 Git 提交 `b3fb7ad`。独立复查的铜间距、定位孔与安装孔避让、网络连通性、跨器件焊盘间距均无异常，详见 [定位孔修复记录](检查记录/usb-slot-repair.json)。**尚需重新导入当前文件，在嘉立创编辑器中重建铺铜并运行正式 DRC**；本地程序的检查不能代替编辑器 DRC。

这是样机评审版。导入后需要重新计算铺铜、完成正式 ERC/DRC、检查封装与核心板实物适配，再决定投板。固件默认禁止行驶，见 [联调与验收](../童骑卫-FW/联调与验收.md)。

设计脚本压缩包保留 `tmp/` 目录结构，只有维护时才需要解压至项目根目录。现用脚本路径已适配 `硬件/`；依赖 Python 3、Shapely 2.x、Pillow，路由器使用 Freerouting 2.5.0。`routed.json` 和 `final-design.json` 已保存本次修复，`carrier.ses` 为修复前历史路由会话，不能直接覆盖现用走线；导入脚本会拒绝其过期位置。本机官方解析脚本还依赖已安装的嘉立创客户端。维护步骤见压缩包内 `README.txt`；路由器、JRE 和 Python 安装包不随工程保存。
