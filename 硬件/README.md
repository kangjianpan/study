# 底板 v2 硬件

只打开本目录的 **`童骑卫-底板v2-PCB样机版.epro2`**，导入嘉立创 EDA 专业版。它包含一页原理图和 130×100 mm 双层 PCB；核心板为现成 TLS-STM32F103C8，不修改核心板。

| 文件 | 用途 |
|---|---|
| [当前工程](童骑卫-底板v2-PCB样机版.epro2) | 原理图、元件、布局布线及底层 GND 铺铜 |
| [BOM](底板v2-BOM.csv) | 139 个元件及采购编号 |
| [逐脚网表](底板v2-逐脚网表.csv) | 427 个符号引脚与对应网络；PCB 物理焊盘 430 个，含 USB 重复焊盘 |
| [外部接口与采购要求](外部接口与采购要求.md) | 采购限制、接口针序和必接的急停线圈回路 |
| [PCB 预览](PCB布局预览.png) | 工程几何数据生成的示意图，不是在线编辑器截图 |
| [检查记录](检查记录) | 独立归档几何检查与本机官方文件解析结果，均不代替在线 ERC/DRC |
| `PCB设计源文件存档.zip` | 手工布局、固定电源/USB路径、路由会话、铺铜及检查脚本的维护存档 |

BOM、逐脚网表已与现用工程核对一致。当前工程 SHA256：`fa81689d7758cb421b85b819280b30f222d73a26fb436a3572142e1b0b261d11`。

2026-11-17 修复了两处同网、不同器件的焊盘重叠。以下坐标为元件中心，单位 mm：

| 器件 | 原位置 | 现位置 | 修复后焊盘边缘间距 |
|---|---|---|---|
| C5 | (40.0, 81.0) | (41.2, 81.0) | L1-2 ↔ C5-1：0.75 mm |
| C50 | (58.0, 91.0) | (58.6, 91.0) | C27-2 ↔ C50-2：0.40 mm |

同步调整了电容相连走线、附近 ESP_RX 走线和 Q4 位号字号，并重新生成底层 GND 铺铜。原理图、封装库和网络定义保持一致。补充的全板检查包含同网跨器件焊盘间距，修复后的间距、连通性、器件本体及文字避让检查均无异常；详情见 [修复记录](检查记录/pad-spacing-repair.json) 和 [归档检查](检查记录/archive-check.json)。这些结果来自独立检查程序；本机嘉立创官方程序仅验证了文件解析，不代表在线编辑器正式 DRC 通过。

这是样机评审版。导入后需要重新计算铺铜、完成正式 ERC/DRC、检查封装与核心板实物适配，再决定投板。固件默认禁止行驶，见 [联调与验收](../童骑卫-FW/联调与验收.md)。

设计脚本压缩包保留 `tmp/` 目录结构，只有维护时才需要解压至项目根目录。现用脚本路径已适配 `硬件/`；依赖 Python 3、Shapely 2.x、Pillow，路由器使用 Freerouting 2.5.0。`routed.json` 和 `final-design.json` 已保存本次修复，`carrier.ses` 为修复前历史路由会话，不能直接覆盖现用走线；导入脚本会拒绝其过期位置。本机官方解析脚本还依赖已安装的嘉立创客户端。维护步骤见压缩包内 `README.txt`；路由器、JRE 和 Python 安装包不随工程保存。
