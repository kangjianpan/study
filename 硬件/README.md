BOM、逐脚网表的电气内容保持不变。当前工程 SHA256：`e59aa72a2c5df3546e0cc77d718ab1a0777bcdffaab0cbf000adb6bb0da02340`。

2026-11-17 将原 130×100 mm PCB 重新布局、布线至 **100×100 mm**，面积减少约 **23.1%**。四个安装孔直径 3.2 mm，孔中心距为 **92×92 mm**，中心坐标为 (4,4)、(96,4)、(4,96)、(96,96) mm。核心板排母间距仍为 15.24 mm，核心板占位尺寸仍为 53.34×22.86 mm；核心板及多数外部接口位置已调整，NFC 接口 J13 从上边移至左边。板框为 100×100 mm，USB-C 等连接器本体可能伸出板边，设计外壳时应另留插拔空间。

新工程保留原工程全部 139 个元件、原理图、封装焊盘尺寸/编号和引脚网络，81 个网络均已布通，顶、底层 GND 铺铜已重建。独立归档检查未发现铜间距、跨器件同网焊盘间距、USB-C 定位孔避让、安装孔/板边避让、器件本体和文字避让错误；本机官方解析器检查也已通过。详见 [现用工程检查](检查记录/archive-check.json)、[电气内容一致性检查](检查记录/electrical-equivalence.json) 和 [官方解析检查](检查记录/official-check.json)。这些检查不替代在线编辑器正式 ERC/DRC。

**原 130×100 mm 版本已由用户在在线编辑器确认 DRC 为 0，存于 Git 提交 `bb92d64`；这个 100×100 mm 版本尚未运行在线正式 DRC。** 导入当前文件后，请重建全部铺铜并重新运行 DRC，再检查核心板和连接器实物适配。若出现“导入更新”提示，应先核对差异，避免旧 PCB 覆盖当前布局。

此前 130×100 mm 版本根据在线编辑器的 11 项“挖槽区域到导线”报错，修复了 USB-C（J15）的两个 0.6 mm 定位孔附近走线。历史版本 e50、e51 到最近走线的距离分别为 **0.331 mm、0.435 mm**。当前 100×100 mm 版已重新布线，按定位孔到铜不小于 0.3 mm 重新检查通过，不沿用历史距离数值。

设计基于用户执行“导入更新”后的工程，保留已同步的元件、封装及焊盘网络；逐脚网表中四条自动命名网络的大小写已同步。修复前的用户工程保存在 Git 提交 `b3fb7ad`，详见 [历史定位孔修复记录](检查记录/usb-slot-repair.json)。

这是样机评审版。导入后需要重新计算铺铜、完成正式 ERC/DRC、检查封装与核心板实物适配，再决定投板。固件默认禁止行驶，见 [联调与验收](../童骑卫-FW/联调与验收.md)。

设计脚本压缩包保留 `tmp/` 目录结构，只有维护时才需要解压至项目根目录。当前脚本位于 `tmp/pcb100/`；依赖 Python 3、Shapely 2.x、Pillow，路由器使用 Freerouting 2.5.0。`routed.json` 和 `final-design.json` 保存最终线路，`carrier.ses` 为补线和电源线宽调整前的路由会话，不能直接覆盖最终线路。本机官方解析脚本还依赖已安装的嘉立创客户端。维护步骤见压缩包内 `README.txt`；路由器、JRE 和 Python 安装包不随工程保存。
