# 童骑卫 GuardKart

STM32F103C8 底板、FreeRTOS 固件、ESP32 网关和微信小程序。

当前版本为**硬件样机与台架联调版**，不是可载人运行的完成品。尚未购买的传感器、轮子、标签和电调需要实测配置；默认禁止行驶。

| 内容 | 入口 |
|---|---|

| 固件与验证方法 | [童骑卫-FW/README.md](童骑卫-FW/README.md) |
| 采购、接线和台架验证 | [童骑卫-FW/联调与验收.md](童骑卫-FW/联调与验收.md) |
| BOM、引脚表、接线及 PCB 预览 | [硬件](硬件) |

项目目录：

```text
童骑卫/
├─ 硬件/               当前工程、BOM、接线表、预览和设计源文件存档
├─ 文档/               方案设计、开发执行规划
├─ 资料/               核心板原厂资料、现用器件手册
├─ 童骑卫-FW/          STM32 固件、Keil 工程、回归测试及验收记录
├─ 童骑卫-Gateway/     ESP32 网关
└─ 童骑卫-App/         微信小程序与 preview.html 页面预览
```

旧 v1、六页原理图、重复源码压缩包和旧修改说明已移出当前目录，可在整理前的 Git 提交 `1ed31f6` 中查找。临时路由器/JRE、下载缓存和可重新生成的编译产物已删除；PCB 设计脚本及必要输入保存在 `硬件/PCB设计源文件存档.zip`。

Git 不跟踪临时工具、构建产物、编辑器状态或 `资料/核心板` 厂家资料全集。源码内不填写云端密钥或 Wi-Fi 密码后上传。首次使用先看 [硬件说明](硬件/README.md) 和 [固件说明](童骑卫-FW/README.md)。
