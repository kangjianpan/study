# 童骑卫 GuardKart

STM32F103C8 底板、FreeRTOS 固件、ESP32 网关和微信小程序。

当前版本为**硬件样机与台架联调版**，不是可载人运行的完成品。尚未购买的传感器、轮子、标签和电调需要实测配置；默认禁止行驶。

| 固件与验证方法 | [童骑卫-FW/README.md](童骑卫-FW/README.md) |
| 采购、接线和台架验证 | [童骑卫-FW/联调与验收.md](童骑卫-FW/联调与验收.md) |
| 外部接口引脚表 | [交付-底板v2/外部接口与采购要求.md](交付-底板v2/外部接口与采购要求.md) |
| 网关 | [童骑卫-Gateway](童骑卫-Gateway) |

旧 v1、六页原理图及 `交付-底板v2` 内的软件压缩包只作历史参考。当前软件以根目录三份源码工程为准，旧构建记录不代表当前验证结果。

Git 不跟踪临时工具、构建产物、编辑器状态或核心板厂家资料全集。厂家资料仍保留在本地。源码内不填写云端密钥或 Wi-Fi 密码后上传。
